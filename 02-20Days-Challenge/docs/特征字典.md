# 特征字典（34 维）

> 对应代码：[`src/vibdiag/features.py`](../src/vibdiag/features.py) 的 `FEATURE_ORDER`
> 数值来源：[`features/feature_summary.csv`](../features/feature_summary.csv)（每类 15 段的均值）
> 计算口径：`raw_audio/*.wav` 裁剪掉首尾各 0.5 s 后的 **2.0 s 稳态段**，采样率 16 kHz

## 0. 怎么读这张表

**「分离度」是我自己定义的一个粗筛指标**：

```
分离度 = (五类均值中的最大值 − 最小值) / 五类类内标准差的平均值
```

它衡量"这个特征能不能把五类拉开"。经验判读：

| 分离度 | 含义 |
| --- | --- |
| > 20 | 强判别力，单靠它就能切开至少两类 |
| 5 ~ 20 | 中等，需要和其它特征配合 |
| < 5 | 基本无信息量（**本表里有 6 个**） |

**分离度不是模型权重。** 分离度大只说明"区分得开"，不说明"模型用到了它"——模型还会考虑特征之间的相关性。真正的权重排名在 [`results/feature_importance.csv`](../results/feature_importance.csv)。

## 2. 三个值得单独讲的特征

### 2.1 `shaft_sideband_ratio`：为"失衡"专门造的判据，它成立了

C3（失衡）的值 **0.231**，其余四类 0.004~0.024——**相差 10~58 倍**，是本表里"单一特征对单一故障"区分得最干净的。

原理：转子不平衡时，重心偏离转轴，每转一圈对轴承座施加一次同频激励。频谱上表现为在 BPF 两侧出现间隔等于**轴频（BPF/5）**的边带群。代码就是照这个算的：取 BPF ± k×轴频（k = 1,2,3）的能量和，除以全带能量。

这个东西不可能是巧合——它是我先知道了失衡的频域长相，才去写的特征。它在最终模型里的权重也排第一。

### 2.2 `autocorr_peak`：遮挡会"毁掉"周期性，而这是最容易忽略的判据

C4（遮挡）只有 **0.190**，其余四类 0.78~0.93。

原理：纸板遮住进风侧后，气流变得紊乱且产生宽带的低频轰鸣（`lf_noise_ratio` 从 0.005 涨到 0.141，**28 倍**），这些不规则的成分把原本清晰的周期结构淹没了。

有意思的是这个特征**不在我最初的预设里**。我原以为遮挡主要影响"能量分布"，没想到它首先破坏的是"周期性"。

### 2.3 `h2_ratio` / `h3_ratio`：两个没用的特征

分离度 1.07 和 1.06，五类均值几乎是同一个数。

也就是说**谐波衰减比在这台设备上不携带信息**——因为风扇的谐波结构主要由叶片几何和转速决定，而转速在 C2~C5 之间几乎相同，叶片又没变形。我保留它们是因为换一台设备（比如叶片有裂纹的风机）它们可能就有用了，但**在这份数据上它们是死重**。

写出来是因为：34 维里塞两个没用的特征，如果不说明，读者会以为"每一维都有理由"。事实是**有两维没有理由**。

## 3. 依赖录音增益的 3 维

`rms_dbfs`、`peak_dbfs`、`bpf_level_db` 是**绝对值**（dBFS），会随手机麦克风灵敏度、AGC、录音距离整体平移。

- 用 `features.feature_names(include_level=False)` 或 `run.py features --no-level` 可整体摘掉，得到 **31 维**纯形状特征；
- 摘掉后交叉验证准确率仍是 100%，但把录音增益改 −24 dB 时，34 维版本掉到 37%，31 维版本**保持 100%**；
- 对比数据见 [`results/stress_gain.csv`](../results/stress_gain.csv) 与 [`REPORT.md` §7.1](../REPORT.md)。

**结论：默认交付 34 维（可解释性好），但建议部署用 31 维。**

## 4. 实现里的三个细节（会影响复现）

1. **整段一次 FFT，不做 Welch。** 2.0 s / 16 kHz 的频率分辨率是 0.5 Hz。Welch 会把分辨率退化到几十 Hz，直接毁掉"BPF/5 次谐波"这个判据（叶片数推定就靠它）。
2. **自相关用 FFT 算，不用 `np.correlate`。** 后者是 O(n²)，32000 点要跑十几秒，75 段就是十几分钟；FFT 版本 O(n log n)，全流程 934 ms。
3. **BPF 搜索区间 60~400 Hz。** 下限避开 50 Hz 市电，上限覆盖到手持小风扇。换设备时改 `features.find_bpf` 的两个默认参数即可。
