## 不要做的事

| 做法                   | 为什么必挂                                                    |
| -------------------- | -------------------------------------------------------- |
| 一次 commit 提交 7 个日志文件 | `git log` 一行就能看出来，这条防线是专门为它设的                            |
| 改系统时间再跑一遍            | 日志 `ts`、文件 mtime、commit 时间三方交叉对不上                        |
| 手写 JSONL 补日期         | `run_id` 分布、`dur_ms` 过于平滑、每天 `notices` 数雷同，`digest` 一眼看出 |
| 把 7 天日志混进多次 commit 里 | 需要改写历史，所有 hash 变化，比原来更可疑                                 |

真实数据即使有瑕疵——某天收件箱为空、某天只有一个通知、某次 OCR 报错——  
也比完美但无从解释的数据可信。**瑕疵就是真实性的证据。**
