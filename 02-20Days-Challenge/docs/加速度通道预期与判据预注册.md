## 二、那一条试采已经确定的观测（不是预测）

| 观测 | 数值 | 含义 |
| --- | --- | --- |
| 主峰 | **100.05 Hz**，x 轴 0.644 m/s² | Hann 主瓣标准形状，频率稳定不漂移 |
| 高档 BPF 应在处 | 177–185 Hz 最大 0.009 | 比主峰低 **71 倍**，等于没有 |
| 转频候选处 | 18–22 Hz 0.0039 / 23–25.5 Hz 0.023 | 比主峰低 165× / 28×，两个候选都缺席 |
| 谐波族 | 50.03 → 100.05 → 200.13 | 比值 **1 : 2.0000 : 4**，交流电机 2f 电磁振动特征 |
| 100 Hz 两侧 (±20 Hz) 边带 | 79.5 Hz 处 0.0075 / 120 Hz 处 0.0059 | 比主峰低 86× / 109×，**几乎无调制边带**；若为叶片通过频率，通常伴随 ±转频 边带 |
| z 轴峭度 | **8.40**（x 轴仅 1.98） | 手机在底座上竖直轻跳，**测量假象**，非设备故障 |

> 该段为 **1 档（低档）**。低档下"5 叶 × 20 Hz = 100 Hz"与"2 × 50 Hz = 100 Hz"**在频率上完全重合**，因此这一段本身**不足以定案**——它只能提供倾向性证据。定案需要 2 档一段（BPF 应移至 181 Hz）：
> 三条证据（无 20 Hz 转频谱线、100 Hz 两侧无 ±20 Hz 边带、与 50.03 Hz 精确 1:2 且存在 4× 分量）都更支持**电磁 2f**，但没有一条能单独排除叶片通过频率。

**由此得到的强先验：这台扇的加速度谱由一个与档位基本无关的 ~100 Hz 电磁分量主导。** 若该判断成立，则"5 叶 × 20 Hz = 100 Hz"这条声学推定在加速度侧得不到支持，`REPORT.md` §3 需按实测重写。

## 三、预期（只写方向，不写编出来的数值）

采集前在这里写下"我预期看到什么方向的变化"，**刻意不写"预计 0.05–0.30 m/s²"这类区间**——那是没有实测依据的数字，写进仓库就成了假精度。75 段采完之后，所有数值一律来自 `results/accel_features.csv`，逐条可查。

前提：手机**刚性绑死**（橡皮筋 + 双面胶贴网壳侧面或立柱），组间不移动；400 Hz；10 s。

| 工况 | 定性预期 | 若不成立，说明什么 |
| --- | --- | --- |
| **C1 / C2 正常** | 1× 与 2× 稳定；两档的 100 Hz 分量**基本一致** | 100 Hz 随档位明显变化 → 它不是电磁分量，是机械分量 |
| **C3 扇叶失衡** | **只抬 1×**（相对 C2 超过 1.3 倍），100 Hz 基本不动 | 1× 与 100 Hz 同升 → 整体松动或手机移位，不能算失衡证据 |
| **C4 进风遮挡** | 振动量变化小，很可能判不出 | 若明显变化，需能给出传递路径解释，否则视为异常 |
| **C5 网罩擦碰** | 峭度**与峰值因子同步**升高，冲击数 > 0 | 只升峭度、不升峰值因子 → 更像磕到底座，不是网罩擦碰 |

三条最值得写死的预期（因为它们都能被推翻）：

1. **C1 与 C2 的 100 Hz 幅值应几乎相同。** 电磁力锁在电源频率上，不随档位变。
2. **C3 只抬 1×、不抬 100 Hz。** 这是失衡最干净的签名。
3. **C5 的峭度与峰值因子必须同向。** 单独一项升高不足以判定擦碰。

> 这三条都不含编造的数字，却都能被实测打脸——这正是它们有用的原因。不能被打脸的"预测"只是事后叙述。

## 四、判据成立与否的判定线（采前定死，采后不改）

| 判据 | 成立条件 | 不成立时怎么写 |
| --- | --- | --- |
| C3 失衡 → 1× 升高 | `a1(C3) / a1(C2) > 1.3`（沿用 `accel_check.py` 现有阈值） | 照实写"1× 判据不成立"，并给出耦合方式的归因 |
| C5 擦碰 → 冲击 | `峭度(C5) > 1.3 × 峭度(C2)` 且 `冲击数 > 0` | 写"低频通道看不到高频故障，须靠声学"，不得淡化 |
| C4 遮挡 → 振动变化 | 预期**不成立**；若 RMS 升 >30% 需给出传递路径解释 | 写"遮挡主要改变气动噪声，不改壳体振动" |
| 4–8 kHz 擦碰指纹 | **永不成立**（物理上限） | 写进局限，不得声称可替代声学 |

## 五、反悔条款

允许改的是**解释**，不允许改的是**阈值**。

如果实测落在预期之外，正确的动作是在报告里写"预期 X，实测 Y，差异的可能原因是 Z"，而不是把阈值从 1.3 调到 1.1 让它成立。**这一页存在的全部意义，就是让"调阈值"这件事在事后无法悄悄发生。**

## 七、实测对照（2026-11-25 21:44–21:53 采完后补写）

采前写下的预期，逐条对照实测（数据见 [`../raw_accel/README.md`](../raw_accel/README.md)）：

| 采前的预期 | 实测 | 结论 |
| --- | --- | --- |
| C3 失衡 → 1× 相对 C2 超过 1.3 倍 | 0.1181 / 0.0227 = **5.92×** | ✅ 预期成立 |
| C3 的 100 Hz 电磁分量基本不动 | 未用 100 Hz 作判据（惰转实验已证明它是电磁，与失衡无关） | ✅ 按修正后的口径执行 |
| C5 擦碰 → 峭度与峰值因子同步升高 | 峭度 **10.63** vs 正常 3.05，冲击数 12.9 vs 0.3 | ✅ 预期成立 |
| C4 遮挡 → 振动量变化小，很可能判不出 | 1× 基本不变（0.0267 vs 0.0227），RMS +19%；但峭度 7.09 明显偏高 | ⚠️ 部分成立：纸板抖动带来冲击，**这正是它容易被误判成擦碰的原因** |
| C1/C2 的 100 Hz 应几乎相同 | 该预期在惰转实验后被判定为无效（100 Hz 属电磁，不能作机械判据） | — 已作废，保留记录 |

**没有调整过任何阈值。** C3 的 1.3 倍与 C5 的 1.3 倍都是采前写死的，实测直接对照。

一条必须写进报告的教训：C4 与 C5 的**数据特征会互相误导**（遮挡那段的峭度 28.1 比擦碰那段更高，因为纸板在抖）。工况标签只能当场记录，不能事后由数据反推——这次是用户确认后才定的标签，若靠数据猜就会把 C4 和 C5 整体对调。
