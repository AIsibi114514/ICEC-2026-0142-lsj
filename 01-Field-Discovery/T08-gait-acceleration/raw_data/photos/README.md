## 三、和大纲要求的对照

大纲第一阶段总则：

> 须包含本校实地采样原始数据表（`raw_data/`）与**本人现场同框照片**

| 判据 | 状态 |
| --- | --- |
| 有本人出镜 | ✅ 1 张 |
| 有场地可识别 | ✅ 水印定位 + 走廊特征 |
| 有采集设备/软件同框 | ✅ 手机 + Phyphox 界面 |
| 拍摄时间与采集同日 | ❌ 11-25 拍，11-12 采 |

**结论：形式满足，时间不满足。** 按"有没有同框照"算补齐；按"能不能证明 11-12 那天你在现场"算不够。仓库根 `README.md` 的缺口表里按「部分补齐」记。

## 四、还差什么（如果时间允许）

按状态各补 1 张，**最好在真实采集的当下拍**，这样时间戳就能对上：

1. 静止：手机置于测量位置，本人 + 手机 + 走廊/场地同框
2. 慢走：走道起点，起步前拍
3. 快跑：同上
4. 楼梯：站在楼梯平台，手机与楼层标识同框

拍摄要求：开时间与定位水印（就像这次这样，水印烧在画面里比 EXIF 更抗"转发丢元数据"）；拍完原图保存，不要经微信压缩。

## 五、为什么不把 20 张截图删掉

删了会让"数据是 Phyphox 采的"少一条最直接的旁证。它们证明不了"本人在场"，但能证明"数据形态与宣称一致"——两件事不是一回事，都有用。

留着 + 标清性质，比留着 + 挂着"现场认证照"的名字好：后者被追问时会同时损失可信度和诚实度。
