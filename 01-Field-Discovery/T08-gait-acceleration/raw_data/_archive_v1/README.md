# _archive_v1 · 第一版采集数据（已废弃，仅作对照）

这四个 CSV 是 **2026-11-12 16:00–16:07** 采集的第一版数据，已不参与当前分析，保留原因只有一个：**`../REPORT.md` 第 2.3 节的「两版数据对比」需要它作为证据。**

## 为什么不删

报告里有一张对比表（实验入口 / 时长 / 窗口数 / 手机贴合度 / 楼梯处理方式），用来说明"同一部手机、同一个人，仅改变采集方式，结论质量完全不同"。没有原始数据，这张表就只是说法，没法核对。

## 这一版有什么问题

| 问题 | 表现 | 后果 |
| --- | --- | --- |
| 实验入口选错 | 用了「含 (g) 的加速度」 | 三轴混入重力，静止读数恒为 9.81 m/s²，必须靠 0.5 Hz 低通做补偿 |
| 时长不足 | 5.9–12.5 s（设计 30 s） | 窗长被迫从 2.0 s 缩到 1.0 s，频率分辨率掉到 1 Hz，**步频判据彻底失效** |
| 手机未贴合 | 快跑段去重力后 RMS 达 34 m/s²（正常 10–15） | 测到的是"手机撞口袋"，不是人体运动 |
| 楼梯混采 | 上楼+下楼录在同一段 | 该类召回仅 44.4% |

## 怎么用

**不要**把它放进 `raw_data/` 顶层——脚本按文件名前缀识别状态，两版同名文件会互相覆盖或产生重复组。

需要复现第一版结论时，临时指定数据目录：

```bash
python ../../scripts/analyze_gait.py --data-dir raw_data/_archive_v1 --fig-dir /tmp/fig_v1
```

注意：第一版是 4 类（`S4_STAIR` 单一类别），当前脚本的 `STATES` 已改为 5 类（拆成 `S4_STAIR_UP` / `S4_STAIR_DOWN`），直接跑会因为状态代号不匹配而跳过全部文件。**要复现 v1，需先把文件名改成当前代号体系。**
