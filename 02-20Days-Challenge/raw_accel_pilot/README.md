> **它不是 `raw_accel/`，不进 5 工况 × 15 段的正式统计，任何报告结论都不得只引用它。**

## 两段的实测阶次分析（这是本目录唯一有分析价值的东西）

| 项 | 1 档（低） | 2 档（高） |
| --- | --- | --- |
| 转频（15–45 Hz 最强峰） | **28.207 Hz**（1692 r/min） | **33.330 Hz**（2000 r/min） |
| 1 阶幅值 | 0.0806 | **0.1892** |
| 2 阶 | 0.0153 | 0.0311 |
| 3 阶 | 0.0089（84.6 Hz） | **0.3367（99.99 Hz ← 主峰）** |
| 4 阶 | 0.0049 | 0.0397 |
| 5 阶 | 0.0026 | 0.0214 |
| 50 Hz 线 | 0.0267 | 0.0265（**几乎不变**） |
| 100 Hz 峰 | **100.062 Hz / 0.644** | **99.922 Hz / 0.337（掉一半）** |
| 100 / 50 比值 | 1.99986 | — |
| 100 / 转频 | 3.5475（非整数） | **2.9979（≈3 阶）** |

三条可直接引用的观测：

1. **「5 叶 × 20 Hz = 100 Hz」被排除。** 20 Hz 带内两档都只有 0.0036–0.0039（比主峰低 160 倍以上），实测转频是 28.2 / 33.3 Hz，对应 1692 / 2000 r/min，与声学推定的 1199 / 2170 r/min 都对不上。
2. **100 Hz 幅值随档位掉一半（0.644 → 0.337），而 50 Hz 线两档几乎相同（0.0267 → 0.0265）。**
3. **200 Hz 附近的峰不可用**：奈奎斯特 200.22 Hz，该峰落在最后 1–2 个频点，属边界/折叠效应，不作证据。

## 100 Hz 仍无法唯一归因（差 0.004 Hz）

| 解释 | 高档预测频率 | 实测 99.922 | 残差 |
| --- | --- | --- | --- |
| 2 × 电源（49.993 Hz） | 99.986 | | 0.064 |
| 3 × 转频（33.330 Hz） | 99.990 | | 0.068 |

分辨率 0.09 Hz，两者相差 0.004 Hz——**频率上不可分**。低档那段则干净地支持 2f（100.062 = 2 × 50.035，比值 1.99986，而 100/28.2 = 3.55 非整数）。

幅值证据同时支持两种相反的读法，因此**不能就此下结论**：
- 掉一半 → 支持"机械 3 阶"（转速相关）；但若是可控硅/分接头调速，电源谐波含量本身也随档位变；
- 50 Hz 不变 → 支持"电源基频未被改动"。

## 断电惰转：100 Hz 定案为「2× 电源电磁」（2026-11-25 21:00 完成）

`g(2).csv`（17.8 s，稳态约 11.7 s 后断电，扇在 1 s 内停转）。0.5 s 短窗跟踪：

| t (s) | RMS | A(100 Hz) |
| --- | --- | --- |
| 11.26 | 0.249 | 0.297 |
| 11.51 | 0.233 | 0.298 |
| **11.76** | **0.159** | **0.028（跌 10.7 倍）** |
| 12.01 | 0.093 | 0.005 |

**断电后 0.25 s，100 Hz 分量衰减 10.7 倍，而整体振动还剩 64%。** 机器仍在转、仍在振，100 Hz 已经消失——机械分量不可能先于整体振动消失，电磁分量可以。

补充证据：这一段真正的 3 阶在 **81.59 Hz**（幅值 0.0359），与 100.09 Hz 是两条独立的谱线（转频 27.195 Hz，3× = 81.6）。上一轮高档文件里"100 Hz = 3 × 33.33"是**巧合**。

### 由此得出三条硬结论

1. **100.09 Hz = 2× 电源频率电磁振动**，与转速无关，不得作为任何机械判据。
2. **「5 叶 × 20 Hz = 100 Hz」这条声学推定链断裂**：100 Hz 不是叶片通过频率，实测转频也与之不符。
3. **实测转频**：本段 27.195 Hz（1632 r/min）、高档段 33.330 Hz（2000 r/min）；声学推定的 1199 / 2170 r/min 分别偏 41% / 8%。

### 仍然未定的：叶片数

阶次幅值 3× 0.0359 / 4× 0.0067 / 5× 0.0053，**没有哪一阶显著突出**，无法从谱上反推叶数。需直接数扇叶。对应关系：

| 叶数 | 低档 BPF (27.2) | 高档 BPF (33.3) |
| --- | --- | --- |
| 3 | 82 | **100（与电磁线重合，永不可分）** |
| 4 | 109 | 133 |
| 5 | 136 | 166 |

## 复现方式

```bash
python scripts/accel_check.py --dir raw_accel_pilot --out results_pilot
```

`accel_check.py` 的默认转频已改为实测值 **27.2 / 33.3 Hz**（原为声学反推的 20 / 36.2），因此

- 不再触发 `[严重] 1× 幅值比 RMS 低 20 倍以上`（旧先验 20 Hz 时低 248 倍）；
- 判据核对会额外打印两条：100 Hz 属电磁分量、叶片数未实数（BPF 按 5 叶占位）。

这次实测也说明了一件事：**转频必须先由实测确定，不能沿用预设值**——同一个脚本、同一份数据，先验从 20 Hz 换成 27.2 Hz，1× 幅值从 0.0008 变 0.0194，差 24 倍。
