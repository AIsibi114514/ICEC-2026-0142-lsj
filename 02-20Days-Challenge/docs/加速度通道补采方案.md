# 加速度通道补采方案（项目三「声振」缺的另一半）

> 现状：`REPORT.md` §8 第 6 条承认"加速度计声道未采集"。这份文档说明**怎么补、补了能答什么、什么答不了**。
> 写于 2026-11-25，用于指导补采；未采之前本文不代表已有数据。

---

## 一、先算清楚：加速度计到底能看到什么

手机加速度计不是"更差的麦克风"，它测的是**壳体振动**，量程和带宽都小得多。台扇的两个关键频率如下（转频由声学已实测反推，见 `REPORT.md` §3）：

| 量 | 低档 1199 r·min⁻¹ | 高档 2170 r·min⁻¹ | 说明 |
| --- | --- | --- | --- |
| 转频 1× | 20.0 Hz | 36.2 Hz | 轴每转一次 |
| 2× | 40.0 Hz | 72.4 Hz | |
| 3× | 60.0 Hz | 108.5 Hz | |
| BPF（5 叶） | 100 Hz | **181 Hz** | 叶片通过频率 |

再对照采样率。手机加速度计常见上限：**200 Hz**（多数机型默认），部分机型可到 400~1000 Hz。**奈奎斯特 = 采样率 / 2**：

| 采样率 | 奈奎斯特 | 低档 BPF(100 Hz) | 高档 BPF(181 Hz) | 4–8 kHz 擦碰指纹 |
| --- | --- | --- | --- | --- |
| 200 Hz | 100 Hz | 恰在边界，不可靠 | ❌ 看不到 | ❌ 永远看不到 |
| 400 Hz | 200 Hz | ✅ | ✅ | ❌ |
| 1000 Hz | 500 Hz | ✅ | ✅ | ❌ |

**三条硬结论，先接受再动手：**

1. **擦碰（C5）的高频指纹（4–8 kHz）在加速度通道上永远不存在。** 这一条不是采样率问题，是物理上限——手机加速度计没有 kHz 级带宽。声学那套"C5 靠 4–8 kHz 宽带摩擦"的判据**不可迁移**。
2. **200 Hz 采样下，高档的 BPF 直接落在奈奎斯特之外。** 采了也看不到，强行分析会得到混叠出来的假峰。
3. **能看到的是 1× / 2× 转频分量、时域冲击性、低频调制。** 这恰好覆盖旋转机械诊断最经典的判据（不平衡→1× 升高；松动/擦碰→谐波与冲击；气流变化→低频底噪），所以这件事**仍然值得做**，只是判据要换一套。

> 如果手机实测只能到 200 Hz：请把采集**全部放在低档**做 1×/2× 阶次分析，并在文档里写明"高档 BPF 不可观测"。不要为了凑 5 工况去测一个看不见的频率。

## 二、手机怎么放（这一步决定数据有没有用）

| 方案 | 做法 | 优点 | 代价 |
| --- | --- | --- | --- |
| **A. 平放网罩顶** | 手机正面朝上平放在前网罩中心 | 贴得最紧，信噪比最好 | 手机自重（约 200 g）压住网罩，**改变被测系统**；且网罩会随手机一起振，测到的是"扇+手机"耦合体 |
| **B. 立在底座旁** | 手机侧立贴住底座侧面，用书夹住 | 不压扇体，更接近"不改动设备" | 耦合松，高频几乎传不过来；一致性差 |
| **C. 绑在立柱上** | 橡皮筋把手机固定在立柱中段 | 折中，可重复 | 需要固定工装，15 段之间易位移 |

**推荐 A，但必须在报告里写清"质量加载效应"**：手机压上去会改变网罩模态与振动传递，测到的是耦合系统的响应，不是裸扇的响应。这不是缺陷，是**测量方式的边界**——面试问"你的传感器有没有影响被测对象"，答得出这一条，比假装无损要好得多。

**15 段之间不许移动手机。** 位移带来的差异会盖过工况差异，整个实验就废了。建议用记号笔在网罩上点一个位置点，每次都对准。

## 三、Phyphox 怎么设置

1. 打开 Phyphox → **「线性加速度」（Linear Acceleration）**，不要用「加速度（含 g）」。
   - 含 g 的版本有 9.8 m/s² 的直流分量，会盖住所有交流特征；若只能导出含 g 的，`import_accel.py` 会自动去均值（等于去重力，仅在手机静止朝上有意义，需注明）。
2. 进设置确认**采样率**：`i` 图标 → 采样率。记下实际值，后面所有阶次分析都依赖它。
3. 录制时长：沿用声学口径 **3.0 s/段**（`raw_audio/` 同口径，便于对时段对齐）。
4. 每段之间**留 2 秒**，让扇体回到稳态，避免上一段的余振串进来。

## 四、采多少、怎么命名

5 工况 × 15 段 = **75 段**，与声学一一对应，命名同构：

```
raw_accel/
├── C1_normal_low_01.csv     # 正常·低档
├── ...
├── C2_normal_high_01.csv    # 正常·高档
├── C3_imbalance_01.csv      # 扇叶失衡（同一片叶根贴 ~1 g 配重）
├── C4_obstruction_01.csv    # 进风侧遮挡（纸板遮后网罩一半）
└── C5_rubbing_01.csv        # 网罩擦碰（前网罩与扇叶轻微间歇接触）
```

**工况操作必须与声学那次完全一致**（配重位置、遮挡面积、擦碰程度），否则两路数据不可比，交叉分析就失去意义。操作定义见 [`工况定义与采集规范.md`](工况定义与采集规范.md)。

### 导出与入库

Phyphox 支持"导出为 CSV"或"导出全部为 zip"。两种都行，`import_accel.py` 都能吃：

```bash
# 1) 把 Phyphox 导出的 CSV/zip 解压后丢进 raw_accel/（文件名随意，脚本按内容识别工况）
# 2) 统一规整：去 g、裁到 3.000 s、按规范重命名、登记 sha256
.venv\Scripts\python.exe scripts\import_accel.py --src <导出目录> --dst raw_accel

# 3) 体检 + 提振动特征（这一步会告诉你采样率够不够、有没有饱和）
.venv\Scripts\python.exe scripts\accel_check.py
```

`import_accel.py` 会在 `raw_accel/sample_index_accel.csv` 里登记：文件名、采样率、原始时长、是否含 g、去均值后 RMS、sha256 前 16 位。

## 五、补了之后能得出什么结论（这才是补的意义）

不要重跑 34 维分类。**加速度通道的价值是"用另一套物理量交叉验证声学的结论"，不是再来一个准确率。**

| 工况 | 声学判据（已有） | 加速度通道应看到什么 | 若看不到说明什么 |
| --- | --- | --- | --- |
| C1/C2 正常 | BPF 主导、谐波干净 | 1× 与 2× 幅值稳定，时域无明显冲击 | 耦合太松，检查手机放置 |
| C3 失衡 | BPF 周边边带 | **1× 幅值显著升高**（不平衡的教科书判据） | 配重太轻（1 g 对 200 g 手机不够）或手机压住了不平衡响应 |
| C4 遮挡 | 100–800 Hz 风噪底抬升 | 低频底噪抬升、RMS 微升 | 遮挡对振动传递影响小，属正常 |
| C5 擦碰 | 4–8 kHz 宽带指纹 | **只剩时域冲击尖峰（峭度、峰值因子升高）**，频谱上看不到高频 | 这是物理上限，写进局限，不要掩盖 |

**预期最有价值的一条**：如果 C3 在加速度上出现清晰的 1× 升高，而声学上是"BPF 边带"——两条独立通道指向同一个物理原因（质量不平衡），这就构成**交叉验证**。这比"我又做了个 100%"强得多。

**预期最诚实的一条**：C5 在加速度上分不出来。这不是失败，是把"声学为什么必须存在"讲清楚了——**低频通道看不见高频故障，这就是双通道的意义**。

## 六、不能做的事（提前划界，免得评审问住）

1. **不能宣称"两路融合提升了准确率"。** 声学已经是 100%（封顶），融合不会更高，只会引入新的过拟合。
2. **不能把加速度特征的 34 维直接套用。** `features.py` 的频带划分到 8 kHz，在 200 Hz 采样下 100 Hz 以上的 5 个频带全是空值，特征会退化成一堆 0。振动通道要用另一套（1×/2× 幅值、谐波比、峭度、峰值因子、冲击计数）。
3. **不能用声学标签去"调"加速度模型再报准确率。** 同一批 75 段既训又测，结果没有意义；要报就报留出法，且注明样本量。
4. **不能补造数据。** 采不到就写"未采"，`REPORT.md` §8 第 6 条已经这么写了，补采失败也照此办理。

## 七、时间估算

| 步骤 | 耗时 |
| --- | --- |
| 固定手机、试采 5 段确认采样率与波形 | 20 min |
| 正式采 75 段（含换工况、留 2 s 间隔） | 60–80 min |
| 导出 + `import_accel.py` 规整 | 15 min |
| `accel_check.py` 体检与特征 | 5 min |
| 写进 `REPORT.md` 新增一节（含"看不到什么"） | 30 min |
| **合计** | **约 2–2.5 小时** |

如果只剩不到 1 小时：**只采 C1/C2/C3 三工况 × 10 段**，专做"失衡的 1× 判据"这一条交叉验证，其余如实写"未采"。**有边界的小实验，比凑满 75 段却分析不动要强。**
